In the box

An engine for Rails

A railtie registers .slim with Action View, and SuperSlim.compile serves plain Ruby. Every - and = stays on its template line, so backtraces point at the right one.

Guide

A formatter that cannot change a page

super-slim format writes one layout, and compiles both versions before writing: if the Ruby differs, it refuses.

Formatter

A linter with HTML and accessibility rules

Rules from slim-lint, haml-lint, erb_lint, Herb and jsx-a11y, each with a flagged and a clean example. The Ruby inside goes to RuboCop, through a plugin.

Linter rules

Tailwind class names

One option, and .rounded-b-[3px], .size-2.5 or .lg:hover:underline work as class shortcuts. Attribute lists keep their meaning.

Tailwind

Nothing new to learn

The whole Slim 5 grammar, the same HTML, the same errors. What SuperSlim leaves out fails at compile time instead of rendering wrong. The grammar is Slim’s, by the Slim Team.

bundle exec super-slim format --check  # in CI
