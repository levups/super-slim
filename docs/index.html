In the box

An engine for Rails and Tilt

A railtie registers .slim with Action View; require "slimx/tilt" serves Sinatra, Hanami and Roda. Every - and = stays on its template line, so backtraces point at the right one.

Guide

A formatter that cannot change a page

slimx fmt writes one layout, and compiles both versions before writing: if the Ruby differs, it refuses.

Formatter

Strict mode

An unformatted template fails to compile, pointing at the first line and what it should be. gofmt discipline, at compile time.

Strict mode

A linter with HTML and accessibility rules

Rules from slim-lint, haml-lint, erb_lint, Herb and jsx-a11y, each with a flagged and a clean example.

Linter rules

Tailwind class names

One option, and .rounded-b-[3px], .size-2.5 or .lg:hover:underline work as class shortcuts. Attribute lists keep their meaning.

Tailwind

Nothing new to learn

The whole Slim 5 grammar, the same HTML, the same errors. What SlimX leaves out fails at compile time instead of rendering wrong. The grammar is Slim’s, by the Slim Team.
