SuperSlim

Slim templates, compiled faster.Same HTML, byte for byte.

Slim is a Ruby template language that writes HTML with indentation instead of closing tags. SuperSlim is a new engine for it, written from scratch: your .slim files keep working and render faster. It comes with a formatter and a linter.

gem "super-slim"

What a template looks like

Nesting replaces closing tags. Lines starting with - run Ruby, = outputs a value escaped for HTML, and the rest are tags, attributes and text. The Slim documentation describes the whole language.

app/views/posts/index.html.slim

ul.posts
  - posts.each do |post|
    li
      a href=post.url = post.title
      - if post.draft?
        span.badge Draft

HTML, with two posts, the second a draft (indented here: SuperSlim writes it on one line)

<ul class="posts">
  <li>
    <a href="/posts/1">Hello &amp; welcome</a>
  </li>
  <li>
    <a href="/posts/2">Next steps</a>
    <span class="badge">Draft</span>
  </li>
</ul>

In the box

An engine for Rails

Add the gem and Rails renders every .slim view with it, with nothing to configure. Outside Rails, SuperSlim.compile returns plain Ruby. Each - and = line compiles onto its template line, so backtraces point at the right one.

Guide

A formatter that cannot change a page

super-slim format rewrites templates in one layout. Before writing a file, it compiles the old and the new version, and leaves the file alone if the Ruby differs.

Formatter

A linter with HTML and accessibility rules

Rules from slim-lint, haml-lint, erb_lint, Herb and jsx-a11y, each shown with a flagged and a clean example. A RuboCop plugin checks the Ruby inside templates.

Linter rules

Tailwind class names

Slim splits or refuses class shortcuts such as .rounded-b-[3px], .size-2.5 or .lg:hover:underline. Turn on one option and they work. Attribute lists keep their meaning.

Tailwind

Nothing new to learn

The whole Slim 5 grammar, the same HTML, the same errors. The few parts SuperSlim leaves out fail when the template compiles, so nothing renders wrong. The grammar is Slim's, by the Slim Team.
